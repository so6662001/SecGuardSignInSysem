# 厂智访客 · 工厂外来人员进出登记系统

> SecGuardSignInSystem —— 门位签到系统
> 用电子化登记替代手工登记本，进出记录实时同步至管理人员，随时查看与审核。

本仓库当前包含**高保真 HTML 原型（界面设计稿）**，用于确认产品形态与交互，作为后续开发的依据。

---

## 一、系统定位与目标

工厂厂区每天有大量外访人员（送货、维修、洽谈、面试、参观等）进出，目前依赖手工登记本，存在**字迹潦草、易漏登、难统计、无法实时同步**等问题。

本系统目标：

- **简单易用**：门卫大字号、大按钮操作，选一选、点一点即可完成，无需培训。
- **直观美观**：扁平化 UI，卡片式布局，信息层级清晰。
- **实时同步**：每条进出记录实时推送到相关管理人员手机，便于查看与审核。
- **低成本租用**：SaaS 订阅模式，**单厂区 ￥60 / 月**，开箱即用、免运维。

## 二、角色与权限

| 角色 | 主要职责 | 使用界面 |
| --- | --- | --- |
| 门卫 / 前台 | 现场访客入场 / 离场登记、发放访客牌 | 门卫工作台、在场访客 |
| 被访人（普通员工） | 接收到访通知、确认接待 | 移动端 |
| 管理人员 / 审核员 | 查看进出台账、审核记录、超时提醒处理 | 进出记录、数据看板、移动端 |
| 超级管理员（老板/安保负责人）| 人员权限、登记规则、订阅账单 | 系统设置、全部 |

## 三、核心业务流程

1. **到访登记**：门卫录入，或访客扫门口二维码自助填写来访信息。
2. **通知被访人**：系统自动推送到被访人手机，被访人确认接待。
3. **入场放行**：核验身份、发放访客牌，记录入场时间。
4. **离场登记**：归还访客牌，一键离场，自动生成台账并计算在场时长。
5. **审核与统计**：记录实时同步至管理人员，可审核、导出台账、查看数据看板。

## 四、原型文件说明（`prototype/` 目录）

| 文件 | 界面 | 说明 |
| --- | --- | --- |
| `index.html` | 产品首页 / 原型导航 | 产品介绍、功能特色、使用流程、￥60/月 定价、各原型入口 |
| `login.html` | 登录页 | 门卫 / 管理员双身份登录 |
| `checkin.html` | **门卫工作台 · 入场登记** | 核心页，大字号快速录入访客信息 |
| `onsite.html` | 在场访客 · 离场登记 | 实时在场名单、一键离场、超时滞留提醒 |
| `records.html` | 进出记录 · 审核台账 | 全量记录检索、筛选、审核、导出 |
| `dashboard.html` | 管理数据看板 | 到访趋势、事由分布、高峰时段、来访单位 TOP、实时动态 |
| `mobile.html` | 移动端 | 访客扫码自助登记 + 管理员移动审核（含手机模型） |
| `settings.html` | 系统设置 | 人员权限、登记规则、通知、门岗、订阅账单 |
| `assets/style.css` | 共享样式 | 扁平化设计系统（配色、卡片、按钮、表格等） |
| `assets/app.js` | 共享脚本 | 演示交互（标签切换、选择块、Toast 提示、实时时钟） |
