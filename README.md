# 厂智访客 · 工厂外来人员进出登记系统

> SecGuardSignInSystem —— 门位签到系统
> 用电子化登记替代手工登记本，进出记录实时同步至管理人员，随时查看与审核。

本仓库当前包含**高保真 HTML 原型（界面设计稿）**，用于确认产品形态与交互，作为后续开发的依据。

---

## 一、系统定位与目标

工厂厂区每天有大量外访人员（送货、维修、洽谈、面试、参观等）进出，目前依赖手工登记本，存在**字迹潦草、易漏登、难统计、无法实时同步**等问题。

本系统目标：

- **简单易用**：门卫大字号、大按钮操作，选一选、点一点即可完成，无需培训。
- **直观美观**：扁平化 UI，卡片式布局，信息层级清晰。
- **实时同步**：每条进出记录实时推送到相关管理人员手机，便于查看与审核。
- **低成本租用**：SaaS 订阅模式，**单厂区 ￥60 / 月**，开箱即用、免运维。

## 二、角色与权限

| 角色 | 主要职责 | 使用界面 |
| --- | --- | --- |
| 门卫 / 前台 | 现场访客入场 / 离场登记、发放访客牌 | 门卫工作台、在场访客 |
| 被访人（普通员工） | 接收到访通知、确认接待 | 移动端 |
| 管理人员 / 审核员 | 查看进出台账、审核记录、超时提醒处理 | 进出记录、数据看板、移动端 |
| 超级管理员（老板/安保负责人）| 人员权限、登记规则、订阅账单 | 系统设置、全部 |

## 三、核心业务流程

1. **到访登记**：门卫录入，或访客扫门口二维码自助填写来访信息。
2. **通知被访人**：系统自动推送到被访人手机，被访人确认接待。
3. **入场放行**：核验身份、发放访客牌，记录入场时间。
4. **离场登记**：归还访客牌，一键离场，自动生成台账并计算在场时长。
5. **审核与统计**：记录实时同步至管理人员，可审核、导出台账、查看数据看板。

## 六、进阶能力：可定制登记项 + 多渠道快速审批

### 6.1 登记项按企业/场景自由定制（`field-config.html`、`checkin-secure.html`）

不同企业、不同来访类型对登记要求差异很大，系统采用**「模块开关 + 登记模板 + 自定义字段」**的方式，做到"要的企业才有，不要的企业不打扰"：

- **登记模板**：普通访客、承包商/施工、供应商送货、面试应聘等，各自独立配置。普通访客保持极简，高安全场景才叠加更多登记项。
- **可开关模块**：基础信息（必备）、证件核验（OCR/人脸）、**携带设备登记**、危险品/物品申报、安全承诺书/保密协议电子签署、健康与防护、车辆信息。
- **携带设备登记**：登记设备名称、品牌型号、序列号/编号、数量、拍照存档；离场时逐项核对，形成进出资产台账，防止设备/信息违规外带。
- **自定义字段**：文本、单选、多选、数字、日期、照片、电子签名、开关等类型，企业可添加专属登记项。

### 6.2 被访人第一时间响应审批（`approval.html`、`approve.html`）

无论被访人**是否接入系统**，都能快速收到并处理访客申请：

| 场景 | 触达方式 | 审批体验 |
| --- | --- | --- |
| 已接入系统 | 小程序 / APP / 公众号 / 企业微信 / 钉钉 实时推送 | 通知栏卡片一键同意/拒绝，秒批 |
| **未接入系统** | **短信内嵌免登录审批短链** | 点开即审批，无需下载/注册/登录 |
| 不便看手机 | AI 语音电话外呼 | "同意请按 1，拒绝请按 2" |

**超时自动升级（防止访客干等）**：首次通知设定响应时限（如 3 分钟）→ 超时二次提醒并换渠道 → 再超时升级到备用审批人/部门负责人 → 最终兜底由门卫电话确认后代审批，全程留痕。

**免审快速通道**：被访人可提前发起「预约邀请码」，访客到场扫码即入；长期合作的送货/维保人员可加入白名单免审。

## 七、多租户 SaaS 与配置化说明

系统采用**多租户 SaaS**模式：上线后面向不同企业提供服务，企业可**在线自助申请开通**，系统为每家企业创建独立空间（专属登录域名 + 数据隔离），按 ￥60 / 厂区 / 月 计费，支持 14 天免费试用。

- **企业侧（租户）**：`signup.html` 在线申请 → `signup-done.html` 开通成功引导 → 进入自己的工作台。工作台顶部显示当前企业空间标识（多租户）。
- **平台侧（我们/运营方）**：`platform.html` 运营后台，审核开通申请、管理全部租户企业、跟踪订阅续费与到期预警、查看月度经常性收入（MRR）。运营后台以紫色系与租户端区分。

补齐的两个功能页：

- **登记规则 `rules.html`**：信息必填项、审批与放行、在场与时长（滞留提醒/当日自动离场/通行时段）、访客牌管理（自动分配/归还/号段）、黑名单与限制、数据留存与隐私（脱敏/授权/保存期限）。
- **门岗管理 `gate-config.html`**：以卡片方式管理多个门岗，设置门岗类型（人行/车行/人车混合）、绑定设备（登记平板、道闸、摄像头、自助码立牌）、分配值守门卫、启用/停用、下载打印每个门岗的**访客自助登记二维码**。
