# 第三方接入切换说明

所有外部依赖均采用「适配器接口 + Mock 实现 + 厂商实现骨架」，通过配置切换；**默认全部 mock**，无需任何真实账号即可端到端运行。

## 配置项（`server/fv-bootstrap/src/main/resources/application.yml` 的 `fv:` 段，可用环境变量覆盖）

| 配置 | 默认 | 可选 | 说明 |
| --- | --- | --- | --- |
| `fv.channel.sms` | `mock` | `mock` / `aliyun` | 短信渠道；`aliyun` 启用 `AliyunSmsChannel`（`dysmsapi20170525`）|
| `fv.channel.sms-config.*` | 空 | — | 阿里云短信 accessKey/sign/template |
| `fv.channel.voice` | `mock` | `mock` / `aliyun` | 语音外呼；`aliyun` 启用 `AliyunVoiceChannel`（`dyvmsapi20170525`，SingleCallByTts）|
| `fv.channel.voice-config.*` | 空 | — | 语音 accessKey / TTS 模板编码 |
| `fv.channel.wechat` | `mock` | `mock` / `official` | 微信模板消息；`official` 启用 `WechatOfficialChannel` |
| `fv.trade.provider` | `mock` | `mock` / `rest` | 交易平台对接；`rest` 启用 `RestTradePlatformAdapter` |
| `fv.trade.base-url` / `api-key` | — | — | 交易平台 REST 地址与密钥 |
| `fv.device.lpr` | `mock` | `mock` / `hik` | 车牌道闸；`hik` 启用 `HikvisionLprGateAdapter`（ISAPI 远程抬杆）|
| `fv.device.lpr-config.*` | — | — | 海康设备地址/账号/密码 |
| `fv.device.ocr` | `mock` | `mock` / `aliyun` | 证件 OCR；`aliyun` 启用 `AliyunOcrAdapter`（`ocr_api20210707`，RecognizeAllText）|
| `fv.device.ocr-config.*` | — | — | 阿里云 OCR accessKey |
| `fv.device.esign` | `mock` | `mock` / `fdd` | 电子签；`fdd` 启用 `FddESignAdapter`（法大大 OpenAPI）|
| `fv.device.esign-config.*` | — | — | 法大大 appId / secret |

## 切换原理
- 短信/语音/微信：Mock 实现用 `@ConditionalOnProperty(havingValue=mock, matchIfMissing=true)`，厂商实现用 `havingValue=aliyun/official`。同一 `code()`（SMS/VOICE/WECHAT）同一时刻仅一个生效，`NotifyService` 按 code 组装渠道 Map。
- 交易平台：`RestTradePlatformAdapter` 命名 `realTradePlatformAdapter` 并按 `fv.trade.provider=rest` 生效；`MockTradePlatformAdapter` 用 `@ConditionalOnMissingBean(name="realTradePlatformAdapter")` 兜底。
- 设备（车牌/OCR/电子签）：`fv-device` 的 `DeviceAdapters` 提供接口与 Mock（`@ConditionalOnProperty` 默认 mock），厂商实现（`HikvisionLprGateAdapter`/`AliyunOcrAdapter`/`FddESignAdapter`）用对应 `havingValue` 生效，每类型仅一个 Bean，调用方无感知。
- 说明：海康 LPR 采用 ISAPI(HTTP) 落地（其 artemis SDK 为本地 jar，不在中央库）；法大大电子签采用其 OpenAPI(HTTP) 落地（无广泛使用的官方 Maven SDK）。生产环境请按各家规范补齐 Digest / HMAC 签名鉴权。

## 接真实厂商的步骤（以阿里云短信为例）
1. `fv-notify/pom.xml` 引入 `com.aliyun:dysmsapi20170525`。
2. 在 `AliyunSmsChannel.send()` 内用 SDK 实际发送（TODO 已标注）。
3. 配置 `fv.channel.sms=aliyun` 与 `fv.channel.sms-config.*`。
4. 无需改动 `NotifyService` 与业务代码。
