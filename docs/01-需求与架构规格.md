# 厂智访客 · 需求与架构规格（开发上下文）

> 本文件是所有 Cursor 开发提示词的**共享上下文**。在执行任何开发提示词前，请先让 AI 阅读本文件与对应的 `prototype/*.html` 原型页面。
> 目标：功能齐全、逻辑不缺失、页面与具体功能完整；覆盖运营平台、PC 端、移动端、所有提醒、所有设备接入。

---

## 1. 产品与角色

多租户 SaaS，两条腿：**通用版**（所有工厂）+ **钢铁厂专属版**（钢厂/钢贸，含车辆/磅单/交易平台打通）。

| 使用者 | 角色 | 主要端 |
| --- | --- | --- |
| 平台运营方（我们） | 平台超管、运营、财务、BD | 运营平台（`/api/ops`，`apps/pc-ops`）|
| 租户企业 | 企业超管、管理员、审核员、门卫、司磅员、被访人/普通员工 | 租户端 PC（`/api/tenant`，`apps/pc-tenant`）、移动端 |
| 外部人员 | 访客、货车司机、承运商 | 移动端 H5/小程序、免登录短链（`/api/public`）|

角色权限用 RBAC（用户-角色-权限-菜单/按钮），权限点细化到「模块 + 操作」。租户可自定义角色。

---

## 2. 总体架构

- 后端 Maven 多模块：`fv-common`(基础/多租户/安全/工具) · `fv-system`(用户/角色/权限/菜单/审计/门岗) · `fv-visitor`(访客通用域) · `fv-steel`(钢铁专属域) · `fv-notify`(通知提醒引擎) · `fv-device`(设备接入) · `fv-billing`(套餐/订阅/账单/报价) · `fv-ops`(平台运营域) · `fv-tenant-api`(租户端聚合入口) · `fv-admin-api`(运营端聚合入口) 或统一网关 `fv-gateway`。
- 中间件：MySQL8（业务库）、Redis（缓存/验证码/排队号/分布式锁/在线状态）、RabbitMQ（异步通知、设备事件、超时升级延时队列）、MinIO（证照/抓拍/磅单/电子签/二维码）、WebSocket（实时）。
- 定时/延时任务：滞留提醒、当日自动离场、审批超时升级、试用到期/续费提醒、账单生成、设备心跳巡检。
- 集成适配层：所有第三方（车牌道闸、人脸、地磅、短信、语音、电子签、微信/企微/钉钉、OCR、交易平台）用 SPI/策略接口 + Mock 实现，配置切换。

## 3. 数据模型（核心表清单）

> 均含公共字段：`id`(雪花)、`create_time`、`update_time`、`create_by`、`update_by`、`deleted`(逻辑删)。租户业务表含 `tenant_id`。

### 3.1 平台运营域（不参与租户过滤）
- `sys_tenant` 租户：企业名称、信用代码、行业、地址、专属域名、状态(试用/正常/欠期/停用)、开通日期、来源。
- `tenant_application` 开通申请：企业资料、联系人、申请套餐、厂区数、证照文件、工商核验结果、审核状态(待审/通过/驳回/补充材料)、审核人/备注、处理进度。
- `biz_plan` 套餐：编码、名称、月单价、计费单位(厂区)、功能项、是否含钢铁模块。
- `biz_addon` 增值模块：编码、名称、计费方式(按月/按量)、单价、适用范围。
- `biz_hardware` 硬件：名称、购买价、租赁月价、类型。
- `tenant_subscription` 订阅：租户、套餐、厂区数、增值模块清单、月费、周期、下次续费日、状态。
- `biz_invoice` 账单：租户、周期、金额、支付方式、状态(已支付/待支付/试用)、时间。
- `biz_quote` 报价单：报价单号、客户信息、明细(JSON)、月度合计、一次性合计、首年预估、有效期、状态。
- `ops_lead` 引流线索：租户、行业信号、推荐产品(交易平台/MES/管理软件)、意向分、状态(待跟进/跟进中/成交/观察)、负责人；`ops_conversion`：转化事件流水（注册→活跃→高潜→商机→成交）。

### 3.2 系统域（租户内）
- `sys_user` 用户（含平台与租户用户，`tenant_id=0` 为平台）、`sys_role`、`sys_permission`、`sys_role_permission`、`sys_user_role`、`sys_menu`。
- `sys_gate` 门岗：名称、类型(人行/车行/人车混合)、位置、值守门卫、自助登记二维码、状态。
- `sys_device` 设备：门岗、类型(登记平板/道闸/摄像头/人脸机/自助码立牌/地磅)、厂商、型号、连接方式、设备密钥、在线状态、心跳时间。
- `sys_audit_log` 审计日志。
- `sys_site` 厂区（多厂区/集团）：名称、地址、负责人；用户/门岗归属厂区。

### 3.3 访客通用域（租户内）
- `visitor` 访客主档：姓名、手机(脱敏)、单位、证件类型/号(加密)、人脸特征/照片、常客标记。
- `register_template` 登记模板：名称、来访类型(普通/承包商/供应商/面试/钢铁车辆)、启用模块、排序。
- `register_field` 登记项/字段：模板、模块(基础/证件/携带设备/危险品/承诺书/健康防护/车辆/自定义)、字段类型(文本/多行/单选/多选/数字/日期/照片/电子签/开关)、是否必填、选项、排序、启用。
- `visit_record` 进出记录：访客、模板、来访事由、被访人、门岗、访客牌号、入场时间、离场时间、在场时长、状态(待审/在场/已离场/异常驳回/超时滞留)、随行人数、车牌、登记人、登记方式(门卫/扫码自助/证件识别)、扩展字段值(JSON)、携带设备明细、承诺书签署记录。
- `visit_approval` 审批：记录、被访人、审批状态(待响应/同意/拒绝/超时升级/门卫代批)、审批人、渠道、时段限制、耗时、流转轨迹(JSON)。
- `invitation` 预约邀请：受邀访客信息、事由、接待人、来访日期/时段、邀请码、二维码、状态(待到访/已到访/已过期/已取消)。
- `blacklist` 黑名单/限制：对象(手机/证件/单位)、类型(黑名单/限制单位)、原因、时间。
- `visitor_badge` 访客牌：号段、状态(可用/占用)、当前记录。

### 3.4 钢铁专属域（租户内）
- `carrier` 承运商：名称、合作状态、准运货物、是否入驻交易平台、白名单标记。
- `vehicle` 车辆：车牌、承运商、车型、准运货物、白名单/受限状态。
- `driver` 司机：姓名、手机、承运商、关联车辆。
- `vehicle_visit` 车辆到厂：车牌、承运商、司机、方向(送货入厂/提货出厂)、关联单据号、货物品名/规格、计划重量、料场/仓库/垛位、安全合规项、排队号、状态(预约/到厂/已登记/过磅/装卸中/复磅/放行)、闭环时间线。
- `weigh_record` 磅单：车辆到厂、地磅设备、皮重、毛重、净重、扣杂率、结算净重、称重时间、抓拍存证、异常(超载/复磅差异)、是否回写交易平台。
- `trade_order_ref` 交易平台单据映射：本地车辆到厂、外部订单/采购单号、客户/供应商、货物、应提/应收量、已提/已收、剩余、结算状态、同步时间。

### 3.5 通知域（租户内 + 平台）
- `notify_template` 模板：编码、渠道(系统推送/短信/语音/微信/企微/钉钉)、标题/内容占位、场景。
- `notify_task` 通知任务：场景、目标用户/手机、渠道链、时限、升级策略、状态。
- `notify_log` 发送日志：任务、渠道、目标、结果、回执、时间。
- `notify_channel_config` 租户渠道配置：渠道优先级、开关、时限、超时升级层级、备用审批人、门卫代批开关。

## 5. API 概览（按端与模块，REST）

> 统一前缀见全局规则。仅列主要端点，实现时补全增删改查与子资源。

### 运营端 `/api/ops`
- `auth`：`POST /auth/login`、`GET /auth/profile`
- `applications`：`GET /applications`(筛选分页)、`GET /applications/{id}`、`POST /applications/{id}/approve`、`POST /applications/{id}/reject`、`POST /applications/{id}/request-materials`
- `tenants`：`GET /tenants`、`GET /tenants/{id}`、`GET /tenants/{id}/subscription`、`GET /tenants/{id}/invoices`、`GET /tenants/{id}/usage`、`GET /tenants/{id}/logs`、`POST /tenants/{id}/renew`、`POST /tenants/{id}/change-plan`、`POST /tenants/{id}/disable`、`POST /tenants/{id}/impersonate`(进入租户空间)
- `plans/addons/hardware`：CRUD
- `dashboard`：`GET /overview`(指标)、`GET /revenue-trend`、`GET /expiring`、`POST /expiring/notify`
- `conversion`：`GET /funnel`、`GET /destination`、`GET /leads`、`POST /leads/{id}/assign`
- `quotes`：`POST /quotes`、`GET /quotes/{id}`、`POST /quotes/{id}/send`

### 公开端 `/api/public`（免登录）
- `POST /apply`(企业申请开通)、`POST /sms/code`(验证码)
- `GET /gate/{gateCode}/template`(扫码取门岗登记模板)、`POST /visit/self-register`(访客自助登记)
- `GET /approve/{token}`(短信免登录审批详情)、`POST /approve/{token}/decision`(同意/拒绝)
- `GET /invite/{code}`(邀请函)

### 租户端 `/api/tenant`
- `auth`、`me/menus`(动态菜单)
- `check-in`：`POST /visits`(入场)、`POST /visits/{id}/checkout`(离场)、`GET /visits`(记录/筛选)、`GET /visits/onsite`、`POST /visits/{id}/audit`(通过/驳回)、`GET /visits/{id}`
- `templates`/`fields`：CRUD + `POST /templates/{id}/publish`
- `rules`：`GET/PUT /rules`
- `gates`：CRUD + `GET /gates/{id}/qrcode`
- `invitations`：CRUD + `POST /invitations/{id}/resend`、`POST /invitations/{id}/cancel`
- `blacklist`：CRUD
- `members/roles`：CRUD、`POST /members/{id}/reset-password`
- `dashboard`：趋势/分布/高峰/TOP/实时
- `sites`：多厂区 CRUD + `GET /sites/overview`(集团汇总)
- `subscription`：`GET /subscription`、`GET /invoices`、`POST /renew`
- `notify-config`：`GET/PUT /notify-config`

### 租户端·钢铁 `/api/tenant/steel`
- `vehicle-visits`：`POST`(登记入厂/出厂)、`GET`(列表/排队)、`POST /{id}/call`(叫号)、`POST /{id}/release`(放行)

## 7. 通知 / 提醒引擎（务必完整）

- **场景**：到访申请待确认、审批结果、入场/离场提醒、超时滞留、当日自动离场、邀请发送、试用到期/续费、账单、设备离线告警、开通申请、磅单异常等。
- **多渠道 + 优先级**：系统推送(WebSocket/小程序订阅) → 短信免登录审批短链 → AI 语音电话 → 微信/企微/钉钉。按租户 `notify_channel_config` 配置顺序触达。
- **超时自动升级**（关键，防访客干等）：首次通知设响应时限(如 3 分钟) → 超时二次提醒(换渠道) → 升级备用审批人/部门负责人 → 门卫代批兜底；用 RabbitMQ 延时队列/延时消息实现，全程写 `notify_log` 与审批流转轨迹。
- **免审快速通道**：预约邀请码、常客白名单命中则跳过审批。
- **模板化**：`notify_template` 占位变量渲染；免登录审批短链 token 有时效、一次性、防篡改。

## 8. 非功能需求

- **安全**：JWT + 刷新令牌；设备密钥 + 签名；`/api/public` 限流与防刷（验证码、短链时效）；越权校验（tenant 隔离、数据权限到厂区/门岗）。
- **合规**：手机号/证件号加密存储、列表脱敏、按角色可见完整信息；信息采集授权；数据留存期限可配置、到期归档。
- **性能**：记录/磅单大表分页与索引；实时推送分频道；导出异步生成。
- **可观测**：统一日志/traceId、审计日志、设备心跳巡检与告警。
- **部署**：Docker Compose（MySQL/Redis/RabbitMQ/MinIO/后端/前端 Nginx）；Flyway 自动迁移；环境配置分离；CI 构建。
- **可运行**：所有第三方 Mock 化，本地一键起服务即可跑通端到端主流程（申请开通→登记→审批→在场→离场→台账；钢铁：车辆到厂→过磅→放行→回写）。
